# The Norse Way — Written Rule Expansions

Full rulebook-style expansions of the mechanics taught in the video series.
Each file is a **complete playable rule** in three beats:

1. **Grounding** — the historical, mythological, or textual roots, with real
   citations from the Mímir-Vörðr scholarly corpus. Homebrew inventions are
   labeled as such.
2. **The Complete Playable Rule** — full mechanics for **D&D 5E** *and*
   **Old School Essentials**, expanded beyond the video: edge cases, examples
   of play, and every number a table needs.
3. **Teaching Beat** — what players absorb about Viking-Age culture by playing it.

Provenance is labeled on every section: Volmarr's canon is law; assistant
additions are marked and never reinterpret him.

## Coverage

- `ep01`–`ep30` — written expansions complete (Episodes 1–30).
- `ep31` and beyond — land here as their video batch publishes
  (Batch G: 31–32).

Each file links back to its episode video (`videos/`) and transcript
(`transcripts/`). Mechanical source of truth: Volmarr's
`HOMEBREW_CODEX.md` (§I–§XXXIII); dual-system reference:
`SYSTEM_VARIANTS.md`.
